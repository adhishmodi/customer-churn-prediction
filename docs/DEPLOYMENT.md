# Phase 7C — public deployment

## Hosting target

Deploy `app.py` from the repository's `main` branch to Streamlit Community
Cloud, using Python 3.12. The app is public and does not provide authentication.
The app may sleep after inactivity under Community Cloud's free-tier behavior;
visitors can wake it when they open the URL.

## Model artifact handling

The app reads two values from Streamlit Secrets:

- `MODEL_ARTIFACT_B64`: Base64-encoded bytes of the trusted
  `customer_churn_model.joblib` generated by Notebook 12.
- `MODEL_ARTIFACT_SHA256`: SHA-256 hex digest of those exact artifact bytes.

The application rejects missing secrets, malformed Base64, oversized
artifacts, malformed checksums, and checksum mismatches before calling the
existing trusted `load_model_artifact()` validator. The temporary artifact
file is created with restrictive temporary-file permissions and removed
after loading. The loaded bundle is cached in the Streamlit process.

Never commit the model artifact, Base64 payload, checksum secrets file, raw
customer data, or customer uploads to Git. Do not accept model binaries from
visitors. The checksum is an integrity check; it does not make an untrusted
joblib artifact safe. Only use the artifact generated by your own Notebook 12
run.

## Prepare the two secrets

Run Notebook 12 and obtain its generated
`models/customer_churn_model.joblib`. In the same trusted Colab runtime (or
after uploading that artifact into a trusted runtime), run:

```python
from pathlib import Path
import base64
import hashlib

artifact = Path("models/customer_churn_model.joblib").read_bytes()
print("MODEL_ARTIFACT_B64 = " + base64.b64encode(artifact).decode("ascii"))
print("MODEL_ARTIFACT_SHA256 = " + hashlib.sha256(artifact).hexdigest())
```

Copy the two printed values into the Streamlit Community Cloud app's Secrets
field in TOML form:

```toml
MODEL_ARTIFACT_B64 = "PASTE_THE_BASE64_VALUE"
MODEL_ARTIFACT_SHA256 = "PASTE_THE_SHA256_VALUE"
```

Do not put the real values in this repository, an issue, a pull request, or a
public notebook. The Base64 value is the private model artifact, not a public
configuration value. If the Streamlit Secrets editor rejects the payload size,
stop and use a separately approved private artifact-storage design; do not
commit the artifact or make a public download URL.

## Create the Community Cloud app

After the Phase 7C pull request has been reviewed and merged:

1. Open the Streamlit Community Cloud workspace and choose **Create app**.
2. Select repository `adhishmodi/customer-churn-prediction`.
3. Select branch `main` and entrypoint `app.py`.
4. Choose Python 3.12 in Advanced settings.
5. Paste the TOML secrets above into the Secrets field and save.
6. Choose a stable custom `.streamlit.app` subdomain, if available, and deploy.
7. Wait for the app to finish starting. A missing/invalid artifact secret must
   leave the app in its safe startup-error state rather than loading another
   artifact.

## Smoke-test checklist

Use synthetic or de-identified records only:

- Open the public URL in a private/incognito browser session.
- Confirm the model loads and the Phase 7A calibration and stored threshold
  appear in the sidebar.
- Submit a synthetic single-customer prediction.
- Upload a valid CSV with exactly the 19 model features.
- Confirm prediction row count/order and download the resulting CSV.
- Confirm missing/extra columns, malformed CSV, and uploads over 10 MB are
  rejected.
- Confirm no model artifact, secrets, or customer rows appear in Git or app
  output. Inspect the downloaded CSV for formula-like values.
- Record the URL and deployment revision only after the smoke tests pass.

## Privacy, access, and operational limits

This app is intentionally public and unauthenticated. Anyone with the URL can
submit requests and consume the shared app resources. The 10 MB upload and
10,000-row batch limits reduce individual request size but are not an
authentication system, rate limiter, or abuse-prevention guarantee. Do not use
real customer personal data or sensitive information in this portfolio demo.

The app itself does not write customer rows to a database or persistent
application store. Uploaded data is still processed by the hosting provider's
runtime; in-memory app handling is not a promise that the hosting provider
never handles data. Community Cloud currently hosts apps in the United States.
Review the provider's current terms and data-handling information before
sharing real customer data.

Community Cloud's free service has resource limits and may hibernate apps
after inactivity. It is suitable for a portfolio demonstration, not a
production customer-facing service with uptime, access-control, or capacity
requirements. No database, external API, or paid service is introduced by this
phase.

## Model and validation boundaries

Phase 7C only packages and serves the already-built Phase 7A model. It does not
train, tune, recalibrate, choose a threshold, or evaluate predictive
performance. The historical 1,409-row holdout remains permanently excluded
from all future work in this phase.
